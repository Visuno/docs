Icon

A line icon by name — or your own SVG — that takes the text colour and themes for free.

Draw an icon by its name, or pass your own path / SVG for a glyph the set does not have. Icons use currentColor, so they take the colour of the surrounding text; size ranges from xs to xl.

Usage

Properties

NameTypeDescription
namestringA canonical icon name (e.g. chevron-right, circle-check). Any of ~5,200 resolves. Optional when you pass path or SVG.
sizexs | s | m | l | xlRendered size: 12 · 14 · 16 (default) · 18 · 24 px.
pathstringA custom SVG path (d of one <path>) drawn on the 24×24 grid.
svg / childrenmarkup / nodesCustom SVG shapes for a glyph the set does not have. Takes precedence over name.
labelstringAn accessible label. With it the icon is announced as an image; without it it is decorative (hidden from assistive tech).
color (Flutter) / style (web)Color / CSSTint the icon. By default it inherits currentColor from the surrounding text.

Only the ~113 names the library itself uses are compiled into each bundle; every other name resolves on demand on the web. On Angular and Flutter, names outside the compiled set are drawn by passing path or svg, so any of the ~5,200 icons — and your own — render everywhere.

Theming

An icon has no colour of its own: it strokes with currentColor, so it matches the text it sits in and switches with light and dark (data-theme="dark") automatically. Set a colour by styling the element (web) or the color parameter (Flutter). The 24×24 grid, 1.75 stroke width and round caps are shared across all four frameworks, so the same glyph looks identical in each.

Badge

A small label for a plan, environment, or status, with an optional dot or icon and an optional remove button.

Progress

A run's progress three ways — a ring for the whole run, segments for its steps and a bar for the step in hand — with controls and an optional meter that warns as it fills.
