Agent run timeline

Every model and tool step of a run on one time axis — a Gantt chart with a playhead, the time each step takes, and the cost as it adds up.

An agent run timeline draws one run as a Gantt chart. Every step is a bar on a shared time axis: the model thinking or writing (purple), a tool like a file read or a test run (teal), or an app the agent works in, such as Figma or GitHub (orange), each with its own mark. A playhead marks now while the run streams and the lanes it has passed take a faint wash; the step at work breathes a ring round its icon and its bar carries a bright leading edge. A failed step hatches red and tags its label, and a retry hangs a dashed line off the end of the step it retries. The key under the title counts how long each kind has run, and the footer adds up the total time, cost, steps and retries. Once the run is done the playhead stops at the finish and turns green.

Usage

Properties

NameTypeDescription
titlestringThe run's name, shown over the status line.
stepsTimelineStep[]The steps of the run, each a bar on the shared axis.
timenumberSeconds into the run. Bars grow up to it and the playhead sits on it. Leave it out once the run has finished.
spannumberSeconds the axis covers. Defaults to the end of the last step, rounded up to a multiple of 4.
ticksnumber[]Labels on the axis, in seconds. Defaults to quarters of the span.
statusstringThe line under the title. Defaults to the steps running now, then "Finished in 11.7s".
statsTimelineStat[]The figures in the footer once the run is done. Defaults to the total time, cost, steps and retries, which count up while it plays.
kindLabels{ model?; tool?; app? }The names of the kinds in the key. Defaults to Model, Tools and Apps.
barebooleanSits flat in a chat thread (the default). Set false to give it a card of its own.

A TimelineStep has a label, an optional icon or brand (an app's own mark, like figma, github or slack), a kind (model, tool or app, which picks its colour), a start and duration in seconds, an optional color, cost, and — for a step that failed — failed, a tag and a note, and retry to hang a dashed line off the step it retries. A TimelineStat has a value, a label and an optional icon.

Theming

Works in light and dark (data-theme="dark") and in the Soft style (data-style="soft"). Each kind keeps its colour from the chart palette — purple for the model, teal for tools, orange for apps — and the playhead runs in the accent, turning green at the finish. In Blueprint the bars square off and a running bar switches from a sweeping sheen to a marching stripe; a failed bar is red and hatched in every theme.
