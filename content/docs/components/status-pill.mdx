A status pill shows a single line of what the agent is up to. Its `state` picks the glyph and
colour — `thinking`, `reading` and `working` shimmer while they run — and a new `state`, `label`,
`file` or `action` fades the old line out before the new one arrives. The `bar` variant is taller
and draws a `progress` track along its bottom.

## Properties

| Name | Type | Description |
| --- | --- | --- |
| `label` | `string` | What the agent is doing, in a few words. Required. |
| `state` | `idle \| thinking \| reading \| working \| waiting \| done` | Picks the glyph and colour. `thinking`, `reading` and `working` shimmer while they run. |
| `meta` | `string` | Quiet detail after the label, like "2 of 4". Changing only this does not restart the pill. |
| `file` | `{ name: string; type?: string }` | A file chip after the label. |
| `action` | `{ label: string; onClick: () => void }` | A button at the end, for when the agent needs the person. |
| `progress` | `number` | 0 to 100, drawn as a track along the bottom of the `bar` variant. |
| `variant` | `pill \| bar` | `pill` hugs its content; `bar` is taller and leaves room for the progress track. |

## Theming

Works in light and dark (`data-theme="dark"`) and in the Soft style (`data-style="soft"`). The pill
sits on a surface with the shared shadow, so it picks up the theme's surface and token colours; in
Soft it is rounder, and in dark it reads against the dark stage.
