A toast is a short message on a surface. Its `tone` picks the icon and colour — `loading` spins —
and it takes a `title`, an optional `description` and an optional `action` button. Pass a new `id`
to slide a new toast in and the old one away; keep the same `id` to change the text in place.

## Usage

<Tabs items={['React', 'Angular', 'Flutter']}>

<Tab value="React">

```tsx
import { Toast, type ToastData } from './toast/Toast';

const [toast, setToast] = useState<ToastData | null>(null);

setToast({ id: 1, tone: 'success', title: 'Deploy succeeded', description: 'Live in production.' });
setToast({
  id: 2,
  tone: 'error',
  title: 'Build failed',
  action: { label: 'Retry', onClick: retry, variant: 'primary' },
});

<Toast toast={toast} onDismiss={() => setToast(null)} />
```

## Properties

| Name | Type | Description |
| --- | --- | --- |
| `toast` | `ToastData \| null` | The toast to show, or `null` for none. |
| `onDismiss` | `(id) => void` | Called by the close button. The toast leaves either way. |
| `toast.id` | `string \| number` | A new id slides a new toast in and the old one away. Keep it to change text in place. |
| `toast.tone` | `success \| error \| info \| loading` | Picks the icon and its colour. `loading` spins. |
| `toast.title` | `string` | The bold first line. |
| `toast.description` | `string` | The quieter line under the title. Crossfades when it changes. |
| `toast.action` | `{ label; onClick; variant?: ghost \| primary \| ink; busy? }` | A button before the close button, like Undo or Retry. |

## Theming

Works in light and dark (`data-theme="dark"`) and in the Soft style (`data-style="soft"`). The card
sits on a surface with the toast shadow and its tone tints come from the theme tokens, so it reads
against the dark stage; in Soft the card and its buttons are rounder.
