**Visuno** is an open-source UI component library for AI-agent products. Every component ships
natively for **Vanilla JS**, **React**, **Angular**, and **Flutter**, from a single shared set of
design tokens — so the look and behavior stay identical wherever you build.

## What's inside

- **Conversation UI** — composers, live answers, voice capture.
- **Agent status** — thinking states, action logs, run timelines.
- **Review & approve** — change reviews, decision prompts, permission gates.
- **Data & workspace** — charts, tables, command palettes, memory panels.

## Theming

All components respond to the same switches:

- Dark mode: `data-theme="dark"` on `<html>` (web); `Brightness.dark` in the Flutter theme.
- Soft style: `data-style="soft"` (web).
